A value that may vary — which seat may message which and with what kind of message, a role, a seat, a topic rule, a threshold, a path — is configuration: data held by the Nexus and set by a query.
Code holds no such value; a value found in code is a configuration baked into code, and is moved out into the Nexus.
Restraint among flows comes from how the components are layered, and from configuration where restraint is wanted; a restriction written into code is against the vision.
