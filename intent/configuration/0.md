description: A value or a decision is being fixed in code, or a hardwired behavior is met.
dependencies: []

No hardwired behavior. Every value and every decision a person might want otherwise is configuration the running system takes: a model, an effort, a threshold, a timeout, a count, a path, a flag, a name, a message a person reads. The code fixes only what cannot differ, and a match on an address, a layer or a model in code is a decision the configuration owed. A hardwired value found is a defect, reported with the configuration it becomes, and the change that lifts it is a release of its own.

A variable is set only for a third-party program, and the value set is itself configuration.

```ethos
; configuration, one value a person sets
Effort.[ Default High Medium Low ]
; the running system takes it, one at a time
Configure.ModelEffort.{ Model Effort }
```
