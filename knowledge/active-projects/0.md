The active repositories, under github.com/LiGoldragon:

- protos, datom-codec, signal: the parsing and wire layers
- ethos-zero: the ethos generator
- nexus: the library that defines the core of a Nexus, its shared traits among it
- flow, with signal-flow and meta-signal-flow: the Flow Nexus, its clients and its contracts
- capsule-nexus, pattern-nexus, each with its signal- and meta-signal- contract repositories: the Nexuses of the complex, version 1
- Curriculum, with signal-curriculum-nexus and meta-signal-curriculum-nexus: Curriculum, version 1
- orchestrate, with signal-orchestrate and meta-signal-orchestrate: Orchestrate, which locks the work across repositories
- lojix, with signal-lojix and meta-signal-lojix: Lojix, which builds and deploys the hosts
- horizon-rs: horizon-lib, the cluster definition Lojix reads
- memory-engine: Memory, the database engine of a Nexus
- energy-nexus, with signal-energy-nexus and meta-signal-energy-nexus: the Energy Nexus
- listener, with listener-library, signal-listener, meta-signal-listener and listener-tests: the Listener, version 1, listener-library holding the types its contracts and its implementation share, and listener-tests its independent contract and Memory scenarios
- book-nexus, with signal-book-nexus and meta-signal-book-nexus: the book tools
- codex-harness-nexus, with signal-codex-harness-nexus and meta-signal-codex-harness-nexus, and harness-nexus-library, the types the Harness Nexuses and the Flow Nexus share: the Codex Harness Nexus
- the test repository of each Nexus above, named <nexus>-tests: its tests
- translator: the translator capsule-nexus and pattern-nexus run
- sema: version 0
- experiment-operation: the trials of operations as objects, Memory and its upgrades, and the trace, pass by pass
- criomos: the hosts
- psyche-pattern, mind-pattern, field-pattern: the pattern modules

A repository not on this list is not maintained; a change wanted in it begins by putting it on the list.
