---
description: The flow command, which sends a message to a thread.
dependencies: []
---

`flow` takes one datom and sends it.

```sh
flow 'Send.{ { Psyche director Opus } MiddleAbrupt.Question.«Is the build green?» }'
flow 'Send.{ { Mind coordinator Sol } HardAbrupt.Order.«Stop the deploy.» }'
flow 'Send.{ { Mind coordinator Sol } MiddleAbrupt.Task.{ 30 «Review the fix.» } }'
flow 'Send.{ { Psyche director Opus } MiddleAbrupt.Living.{ «what his words were about» «his words» } }'
flow 'Send.{ { Psyche director Opus } MiddleAbrupt.Notice.«The fix is landed.» }'
flow 'Send.{ { Psyche director Opus } MiddleAbrupt.Result.{ k7ph «Yes, green.» } }'
flow 'Send.{ { Mind coordinator Sol } MiddleAbrupt.Done.{ m2x9 «Reviewed.» } }'
```

An address is `{ Aspect topic Model }`. Text is in «guillemets».

A request arrives with a four-character id. A Result answers the Question of that id; a Done closes the Task of that id; the 30 is the Task's minutes.

MiddleAbrupt is plain sending, the same as the living typing: every message is sent MiddleAbrupt. HardAbrupt is Escape, then sending. Soft is unusable outside testing until it works: it holds the message until the recipient's turn ends, and a Soft Notice is never delivered on its own. A Notice asks nothing and wakes no sleeping thread.

`SendAccepted.{ k7ph 1821 Queued }` means the message is admitted.

A message holding an apostrophe goes through a variable:

```sh
m=$(cat <<'END'
Send.{ { Psyche director Opus } MiddleAbrupt.Notice.«It's landed.» }
END
)
flow "$m"
```
