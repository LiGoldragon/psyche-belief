## The marks

Each mark fits a box 130 wide and 130 high centred on its place, except Sūrya, 170. Clear, glossy, flat colour, no shadow, no outline other than what is named.

```datom
[ { Sūrya   Disc.{ Radius.60 Fill.#C4622D }
            CentrePoint.{ Radius.11 Fill.#F2B33D }
            Rays.{ Count.12 Straight From.66 To.85 Stroke.#C4622D Width.5 } }
  { Candra  Crescent.{ HornsUp OuterRadius.60 Fill.#F4F7FA Edge.#9FB3C8 EdgeWidth.3 } }
  { Maṅgala Triangle.{ PointUp Side.120 SharpCorners Fill.#C81E2B } }
  { Budha   Square.{ Side.70 Fill.#3F8F3A } }
  { Guru    Ring.{ OuterRadius.65 StrokeWidth.12 Stroke.#E3A712 Fill.None } }
  { Śukra   Rosette.{ Petals.8 Even OuterRadius.60 Fill.#FBF7F0
                      Edge.[ #E58FB0 #6CC5C0 #E9C46A #9A7BD0 ] EdgeWidth.4 } }
  { Śani    Bar.{ Width.26 Height.130 Upright Fill.#141B3F } }
  { Rāhu    Head.{ Arc.{ OuterRadius.60 OpenMouthToward.Centre Fill.#2E3A5C Opacity.60 } NoBody } }
  { Ketu    Banner.{ Crest.{ Height.70 Fill.#8A8F99 Tip.#D9662B }
                     Trail.{ Smoke Fraying Holes.3 Fill.#8A8F99 } NoHead } } ]
```

Śukra's edge runs through its four colours in order round the rosette, two petals each. Rāhu's open mouth faces Sūrya. Ketu's trail points away from Sūrya.

## The words

Under each mark, centred: its name, 30 px, ink, bold; under the name, its place in the cosmic person, 26 px, ink (varahamihira: Bṛhajjātaka 2.1; Rāhu and Ketu have none there, and take what they are).

```datom
[ { Sūrya soul } { Candra mind } { Maṅgala strength } { Budha speech }
  { Guru knowledge } { Śukra desire } { Śani sorrow }
  { Rāhu shadow } { Ketu portent } ]
```

The sheet holds no other word, no line between marks, no title and no legend.
