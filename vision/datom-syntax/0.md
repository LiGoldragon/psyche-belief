How a datom is written. Its type is known from its position before the text is read, so the text carries only the data.

## The types, in Ethos

```ethos
Library
[]
[ Name.String
  Year.Integer
  Address.{ Street.String
            City.String
            PostalCode.String }
  Role.[ Author
         Reviewer.{ Year Reviews.Integer } ]
  Person.{ Name Year Address ⟦Role⟧ }
  Reply.[ Accepted.{ Person Option<Year> }
          Refused.String
          Pending ] ]
[]
[]
```

## A Person

```datom
{ Ada
  1990
  { «12 Rue de la Paix» Paris 75002 }
  [ Author
    Reviewer.{ 2024 17 } ] }
```

| in the datom | is |
|---|---|
| the outer brace | a struct: its positions in order, no names |
| `Ada` | a string, written bare: it has no space and no delimiter |
| `1990` | an integer: bare decimal, no leading zero, no plus |
| `«12 Rue de la Paix»` | a string in guillemets: it has spaces |
| `75002` | a string, because its position says String |
| the bracket | a vector |
| `Author` | a variant carrying nothing |
| `Reviewer` | a variant: its head, a dot, then what it carries |

## Three Replies

```datom
Accepted.{ { Ada
             1990
             { «12 Rue de la Paix» Paris 75002 }
             [ Author ] }
           Some.2026 }
```

```datom
Refused.«no such person: { } is content, and so is «this»»
```

```datom
Pending
```

| in the datoms | is |
|---|---|
| `Some.2026` | an Option is written `Some`, a dot and the value, or `None`; a Result is `Ok` or `Err` the same way |
| inside the guillemets | every glyph is content; a pair of guillemets inside nests, and one left unbalanced takes a backslash |
| the spaces | one inside every brace and bracket, at both ends; none inside guillemets |
| the lines | a structure of leaves sits on one line; one whose element has a next layer hangs its elements beneath the first |

A semicolon opens a comment, which runs to the end of its line.
