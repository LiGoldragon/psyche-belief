## A Claude thread is started without the Artifact tool

No Claude thread is started with the Artifact tool, except the threads of the publishing faculty. The tool costs every thread that carries it some twenty thousand tokens, and publishing is the publishing faculty's work.

Whoever writes or changes a thread's configuration checks this before the thread is started.

## Every thread is refreshed at its model's size

Each model has a refresh size, in tokens of context: below its context window, and no higher than the size above which its price rises. As set now, Astra's and Luna's are 250,000, under their window of 258,400; Sol's and Terra's are 272,000, the size above which their price rises. A Claude model's size is set once its window is measured.

The Loom tells a thread ahead of its refresh size, so that the thread writes its handover. At the refresh size the Loom starts a fresh thread from that handover and closes the old one.

## A thread can always be refreshed

Refresh and restart work on a thread in every state: working, resting or cold. A thread that cannot be refreshed is a fault of the Loom, repaired before any other work on the Loom.
