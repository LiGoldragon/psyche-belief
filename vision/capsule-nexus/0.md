# The Capsule Nexus

The Capsule Nexus owns every pane. Herdr is its backend, and it is the one component that runs herdr; when herdr changes, it changes, and nothing else does. It is built first, because it proves the translator and the CLI alone, and it is kept usable by hand: any flow, or the living, drives a pane through `capsule 'Prompt.{ … }'`.

## Signal
The Capsule Nexus also observes: a pane's state is read from herdr and pushed to subscribers as it changes, so the Flow Nexus learns a harness has died without a hook. A pane carries a label, the address of the flow in it, so a listing reads as the definition does.

```ethos
Signal
[ capsule:[ Session PaneId Pane Workspace
          Command Text Keys Outcome Label State ] ]
[ Create.Workspace
  Start.{ Pane Command Label }
  Prompt.{ Pane Text }
  Press.{ Pane Keys }
  Close.Pane
  List.Session
  Subscribe.Session ]
[ Created.Outcome
  Started.Outcome
  Prompted.Outcome
  Pressed.Outcome
  Closed.Outcome
  Listed.Outcome
  Subscribed.Outcome
  Changed.{ Pane State } ]
[]
```

## Meta

Configure sets one value of the configuration at a time, never the whole; a subscription follows the configuration as it changes. SubscriberCapacity is positive, and an active subscription follows it. The meta surface, the root of the Nexus, may act on any pane; the ordinary surface acts only on the panes its caller owns.

Set has one type per field, the translator-owned fields first and the Nexus-owned after, SubscriberCapacity positive; a peer's identity is checked by kernel credentials. Configured answers the value set, its keeper and readiness, which lists the fields still unset; ConfigureRefused answers why the value was not set: a value refused, a peer unknown to remove, or a target that is not up.

## Library

A Session is the herdr session, a CreationId marks a creation, a PaneId is herdr's name for a pane, a Root is a directory, a Command is what starts in the pane with its arguments, and an Executable is the kind's program; AgentKind lists herdr's agent kinds, and Text is what is typed. A Refusal is herdr refusing, a TransportRefusal is the connection being refused, and an Owner is a text caller by its login or a signal peer by its binding. Attempt is how the last attempt on a pane ended, ObservedEffect is what herdr was seen to do, StorePhase is when the store failed, and Outcome is how every attempt ends.

## Operation

One attempt per input. An attempt reads and writes Matrix and may compose several Emissions, each one herdr call; every attempt ends in the shared Outcome. The Operation turns what the Emission observed into the shared Outcome.

```ethos
Operation
[ capsule:[ Session Pane Workspace
          Command Text Keys Label ]
  :capsule:AttemptOutcome.Outcome ]
[ Creating.Workspace
  Starting.{ Pane Command Label }
  Prompting.{ Pane Text }
  Pressing.{ Pane Keys }
  Closing.Pane
  Listing.Session
  Subscribing.Session ]
[ Created.AttemptOutcome
  Started.AttemptOutcome
  Prompted.AttemptOutcome
  Pressed.AttemptOutcome
  Closed.AttemptOutcome
  Listed.AttemptOutcome
  Subscribed.AttemptOutcome ]
[]
```

## Emission

The herdr command line, as a type. The translator turns it into the call. Its outcome is what the translator observed, raw and its own type. Listing composes PaneList and AgentList, and WorkspaceList while a creation is pending; each is one herdr call.

AgentStart's Timeout comes from the configuration.

```ethos
Emission

          Variable Command Text
          Keys State Refusal
          CreationId ] ]

                           Root

         Keys.{ PaneId Keys }
```

```rust
impl Emittable for Herdr {
    type Outcome = ExternalOutcome;
    fn emit(&self, t: &Translator) -> ExternalOutcome {
        let mut argv = vec!["--session".into(),
                            self.session.0.clone()];
        argv.extend(self.verb.argv());
        t.call(&t.herdr_path, &argv)
    }
}
```

## Matrix

A pane is owned by an Owner. A text caller, through the translator, owns by its login, since a CLI is a new process each call and one person drives a pane across many. A signal peer, such as the Flow Nexus's translator, owns by its Peer entry, bound by kernel credentials. The envelope carries the Caller, its ProcessId and UserId, and ownership derives from it.

For the proof of concept, Matrix lasts as long as the process.

An OwnedPane records an owned pane and who owns it, every change returns an Answer, and a PendingCreation is a creation not yet joined to its pane.

```ethos
Matrix
[ capsule:[ Owner Pane Workspace Label
          State Attempt
          MatrixRefusal CreationId ]
  translator:[ Principal ] ]
[ OwnedPane.{ Owner Pane Workspace
              Option<Label>
              State Attempt }
  Answer.[ Succeeded
           Failed.MatrixRefusal ]
  PendingCreation.{ CreationId
                    Principal
                    Workspace } ]
```
