## Code is written anatomically

Code is written anatomically and directly: the logic is read through
the ontology of the trait system. Datom and Ethos Zero are the parts
that must be solid.

A well-written machine looks like an organic being: its parts are in proportion, and its shape fits what it does. Code that keeps growing in one direction is missing an abstraction: a truck seventy-three meters long is a train not yet seen, which needs its carts linked and a rail to run on, or a fleet of trucks, which needs a coordinator and its drivers; which of them, the ground it is to cover decides.

Whenever the design expands into another part of the system, the designer steps back: where does this part fit, and does its shape fit its intended use? The answer may be that the whole anatomy is redone, because this is a different animal.

To write a machine, its anatomy is made first: its parts, each described by what it can do. What several parts can each do is a trait; each part does it in its own way.

The example is our own. Every Nexus sends calls to the part of the world it has no Signal contract with, and today each one carries its own hand-written translator, the sockets and the text copied from the one before: the truck, a little longer with each Nexus.

The anatomy: what all those calls can do is be emitted. That is the trait. The Ethos, from the Source Nexus: Resolve asks which revision a reference stands at, Fetch asks for one revision's content, each carries the path of the program it calls, and each emission has one outcome, in the same order, of what the translator observed.

```ethos
Emission
[ source:[ Git Nix Repository Reference Revision ] ]
[ Resolve.{ Git Repository Reference }
  Fetch.{ Nix Repository Revision } ]
[ Resolution.[ Resolved.Revision
               Unresolved.Integer ]
  Fetching.[ Fetched
             Unfetched.Integer ] ]
[]
```

The Rust written by hand: each part's own way of doing it, and nothing else. The serving, the sockets and the text are written once, for every Nexus.

```rust
impl Emittable for Resolve {
    type Outcome = Resolution;
    fn emit(&self) -> Resolution { self.git.remote_revision(&self.repository, &self.reference) }
}
impl Emittable for Fetch {
    type Outcome = Fetching;
    fn emit(&self) -> Fetching { self.nix.fetch(&self.repository, &self.revision) }
}
```
