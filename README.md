# psyche-skills

This repository holds the Psyche aspect's authored skill sources in a mixed
layout. Direct sources in `skills/*.md` use their filename as their skill
name. Vision topic sources in `vision/*.md` use the logical name
`vision-<filename>`; for example, `vision/ethos.md` is `vision-ethos`.
Other Vision sources remain directly named in `skills/` with the `vision-`
prefix. Intent sources use the `intent-` prefix, and `skills/spirit.md` is
the unprefixed Spirit source.

The Psyche aspect owns this repository. Another aspect's flow that wants a
change contacts Psyche, which investigates it and brings a change to the
living.
